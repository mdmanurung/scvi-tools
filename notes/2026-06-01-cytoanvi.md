# Lab notes — cytoanvi (2026-06-01)

**Takeaway:** CytoANVI (a SCANVI-style semi-supervised extension of CYTOVI) plus a paper-faithful cscanvi continual case-control update are implemented in-repo and pass 13/13 synthetic tests; the design was corrected twice against source/paper, but nothing is validated on real cytometry data and the branch is not pushed.

## Goal
- Build **CytoANVI** = CYTOVI + cell-type classifier head + partial-label objective (as SCANVI extends SCVI), for annotation-aware integration.
- Then (Phase 2) add a **continual case-control update** porting `theislab/comparative_atlas` (`cscanvi`) so the model can be a reference that integrates new query cohorts while leveraging healthy controls.

## Narrative — what I tried & observed
- Architecture grounded in source: **TOTALANVI is the exact precedent** (`TOTALANVAE(SupervisedModuleClass, TOTALVAE)` + `TOTALANVI(SemisupervisedTrainingMixin, TOTALVI)`); CytoANVI mirrors it 1:1. Reused inherited `classify`/`classification_loss` (x arrives pre-masked via CytoVAE `_get_inference_input`).
- Phase 1 bug found+fixed: `from_cytovi` latent reproduction failed only because an unfit module stays in **train mode** (dropout/BN) — `get_latent_representation` doesn't force eval; fixed in test by `module.eval()`.
- Phase 2 first cut followed the **cscanvi code** (EWC penalty only; replay buffer used solely for Fisher). Two correctness fixes via review: (1) EWC `old_params` must be snapshotted from the **reference** module not the query (resized-batch shape mismatch) — `3eeb1fd8`; (2) control importances computed on the **batch-extended query model** — `bf34dcba`.
- Then re-grilled against the **actual paper** (Methods pp.18-19, read from `cscanvi-paper.pdf`): the released code **diverges from the paper** — paper's loss rehearses the replay buffer in the ELBO and combines Fisher by **Hadamard product** `F_ref ∘ F_query_ctrl`. Reimplemented to match the paper (`06371a55`): experience replay in the training step, product default, query controls required, TTA mask 50%.
- Tests: **13/13 pass** (`cytoanvi` suite, ~10-20s, scvi-test conda env via PYTHONPATH). Example runs end-to-end: reference label-transfer acc **0.467** (>0.25 chance); query acc ~chance (expected — synthetic ref/query independent).
- PR-derisk: ruff (repo pinned v0.15.14 config) clean; all **22 external models import** incl CytoANVI; `cytovi` sibling suite 3 pass / 2 skip / **1 fail = missing optional `fcswrite` dep** (pre-existing env gap, not my change).

## Decisions & rationale
- **M2 architecture, GMM prior off** — see `docs/adr/0001-cytoanvi-m2-over-gmm-prior.md`.
- **Follow the paper, not the released code, where they disagree** (experience replay + product Fisher) — see `docs/adr/0002-cytoanvi-continual-follows-paper-not-code.md`.
- **`ewc_importance` not defaulted to the paper's 100** — CytoVI's intensity-likelihood Fisher scale differs from scANVI/RNA; documented as needing retune. Verdicts for all divergences captured in `INVESTIGATION.md` ("Divergence verdicts").
- Sourcing rule (user): use the primary paper, never substitute repo/README without permission (`~/.claude/.../memory/primary-source-only.md`).

## Open questions / dead ends / next

- **Tune `ewc_importance` (λ)** for CytoVI — paper's 100 won't transfer.
